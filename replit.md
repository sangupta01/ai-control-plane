# AI Control Plane — Workspace

## Overview

Production-grade AI Gateway + Full LLM Observability Platform. pnpm workspace monorepo using TypeScript. All features complete and tested (53/53 tests passing).

## Stack

- **Monorepo tool**: pnpm workspaces
- **Node.js version**: 22
- **Package manager**: pnpm
- **TypeScript version**: 5.9
- **API framework**: Express 5
- **Database**: SQLite (better-sqlite3, WAL mode) — 4 tables: traces, security_events, eval_results, sessions
- **Validation**: Zod (api-zod lib, generated by Orval)
- **API codegen**: Orval (from OpenAPI spec in lib/api-spec/openapi.yaml)
- **Build**: esbuild (ESM bundle, better-sqlite3 externalized)
- **Dashboard**: React 18 + Vite + Tailwind v4 + shadcn/ui + TanStack Query + wouter

## Key Features

- Unified LLM Gateway (`POST /api/v1/chat`) — 5 mock models
- Session Sticky Routing with affinity-based cost-aware model selection
- Security Guardrails — 5 scanners: PII, secrets, prompt injection, jailbreak, data exfiltration
- Policy-as-Code — 18 YAML rules (config/policies.yaml), hot-reloadable
- Heuristic Eval Scoring — relevance, safety, hallucination risk, groundedness
- AI Incident Replay — re-run traces with alternate models, side-by-side eval diff
- Cost Insights — per-session/tenant/prompt cost analysis, optimization suggestions
- Red Team Testing — adversarial scenario runner
- Real Provider Adapter — `PROVIDER_MODE=real|hybrid` routes to OpenAI/Anthropic with mock fallback

## Key Commands

```bash
# Development (Replit)
pnpm --filter @workspace/api-server run dev   # API server
pnpm --filter @workspace/dashboard run dev    # Dashboard

# Testing
make test-all API_URL=http://localhost:80/api  # all 53 tests
make test                                      # 22 baseline
make test-features                             # 24 feature tests
make test-replay                               # 7 replay tests

# Validation
make validate                                  # all tests + demo

# Workload generation
make workload-enterprise API_URL=http://localhost:80/api

# Database
make reset-db                                  # delete local DB

# Codegen
pnpm --filter @workspace/api-spec run codegen  # regenerate hooks + Zod schemas from OpenAPI
```

## Architecture

```
artifacts/api-server/src/
  index.ts        → app.ts → routes/index.ts
  modules/
    gateway.ts    # processRequest() — central orchestrator
    routing.ts    # session affinity + cost-aware model selection
    security.ts   # 5 regex-based scanners
    policies.ts   # YAML rule engine (config/policies.yaml)
    evaluation.ts # heuristic scoring
    providers.ts  # mock + real LLM adapter (PROVIDER_MODE env)
    storage.ts    # SQLite singleton — all DB access
    cost-insights.ts
    redteam.ts

artifacts/dashboard/src/
  pages/          # Overview, Traces, Security, Sessions, Evals, Demo, Policies, CostInsights, RedTeam

lib/api-spec/openapi.yaml   # API contract (source of truth)
lib/api-client-react/       # Generated TanStack Query hooks
lib/api-zod/                # Generated Zod validators
config/policies.yaml        # 18 policy rules
scripts/src/                # test_suite.ts, test_features.ts, test_replay.ts, generate_workload.ts
data/                       # Persistent local SQLite (gitkeep)
docs/                       # CODEBASE_GUIDE.md, ARCHITECTURE_DIAGRAM.md, LOCAL_RUN.md, DEMO_SCRIPT.md
```

## Environment Variables

| Variable | Required | Notes |
|---|---|---|
| `PORT` | Yes | API/dashboard server port |
| `BASE_PATH` | Yes | URL prefix (`/api` for server, `/` for dashboard) |
| `DB_PATH` | No | SQLite path, default: `./control_plane.db` |
| `PROVIDER_MODE` | No | `mock` (default) / `real` / `hybrid` |
| `OPENAI_API_KEY` | No | Required for real GPT model calls |
| `ANTHROPIC_API_KEY` | No | Required for real Claude model calls |
| `DEFAULT_MODEL` | No | Model used when none specified |

## Important Notes

- All DB access goes through `storage.*` — never import better-sqlite3 directly elsewhere
- Never use `console.log` in server code — use `req.log` in routes, `logger` singleton elsewhere
- Schema changes: additive only (ALTER TABLE ADD COLUMN in try/catch in initSchema)
- OpenAPI spec is the contract — add endpoint there first, then run codegen
- Policy changes don't need restart: `POST /api/v1/policies/reload`
- Replay endpoint (`POST /api/v1/traces/:id/replay`) has no generated hook — added after spec freeze
- All 53 tests must pass before any merge
