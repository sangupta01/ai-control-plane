## Feature: AI Incident Replay

### New Endpoint

POST /api/v1/traces/:id/replay

Request body:
{
  "override_model": optional string,
  "override_routing_strategy": optional string
}

---

## Behavior

1. Fetch original trace:
   - prompt
   - tenant_id
   - user_id
   - session_id
   - app_id
   - original model
   - original routing strategy

2. Re-run the request through gateway pipeline:
   - security pre-check
   - routing (with optional override)
   - provider
   - evaluation
   - observability

3. Store replay as NEW trace:
   - include field:
     "replay_of_trace_id": "<original_id>"

4. Return:

{
  "original_trace": {...},
  "replay_trace": {...},
  "diff": {
    "response_changed": true/false,
    "model_changed": true/false,
    "eval_diff": {
      "relevance": delta,
      "safety": delta,
      "hallucination": delta,
      "groundedness": delta
    },
    "routing_changed": true/false
  }
}
